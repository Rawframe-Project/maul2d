# the library's floating-point environment (src/fpenv.h), under the
# reason they need not: a reason is a line ending in a colon, its names
# indented below it. A function belongs here only if it reads or writes
# stored values, ids and flags, or fills a def with constants: no float
# is computed, rounded or compared. Every other public function enters
# the environment; tools/check_float_env.py checks both ways.
